# Security policy

Please do not open a public issue for a vulnerability that could expose local
conversations, source code, credentials, files, or model-provider API keys.

Report it privately to the maintainer:

- GitHub: https://github.com/fayzkk889
- X: https://x.com/tana_shahh

Include the Lore version, operating system, clear reproduction steps, and the
kind of data that could be affected.
