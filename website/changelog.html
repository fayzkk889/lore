0.10.0-alpha.9-mcp — Windows via Ubuntu WSL 2

This developer preview ships the Lore memory engine as a local MCP server. It does not ship Lore’s original standalone coding agent or a new native Windows executable. Codex on Windows was tested end to end through Ubuntu WSL 2: a fresh task called Lore, retrieved project evidence and cited the original chat.

The release tightens project matching across Windows and WSL paths, filters chat scaffolding from retrieved evidence, and keeps uncertain counts or named-person claims from being presented as proven facts. Local Codex, Claude Code and Qwen Code sessions can be discovered when their files are accessible.

The older Windows executable and browser extension preview are outside this package. Other MCP clients still need their own validation. See the setup guide and scope limits.
