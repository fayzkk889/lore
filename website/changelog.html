0.10.0-alpha.11-mcp — MCP memory preview

This developer preview ships the Lore memory engine as a local MCP server. It does not ship Lore’s original standalone coding agent or a new native Windows executable. Codex and Claude Code on Windows were tested in both directions through Ubuntu WSL 2: each retrieved the other's project history with message citations.

This update also keeps synthetic Codex approval-review sessions out of the all-sources memory list and accepts ordinary Windows file paths when importing chat exports through the WSL MCP server. It handles plain requests for the latest work in a named agent and includes Claude Code setup. It preserves source citations and the previous project-matching safeguards. Local Codex, Claude Code and Qwen Code sessions can be discovered when their files are accessible.

The older Windows executable and browser extension preview are outside this package. Other MCP clients still need their own validation. See the setup guide and scope limits.
