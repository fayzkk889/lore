Browser project-memory preview

Optional Chrome/Edge capture of enabled, opened conversations. Project-context retrieval and draft insertion use the local Lore engine. The extension preserves existing drafts, pauses capture, reports unsupported layouts and handles recognized streaming responses.

Browser timestamps are explicitly marked as capture times. Stable-ID corrections replace turns; layouts without IDs use content hashes with edited-history limits. Windows concurrent lock-file contention is handled with a bounded retry.

Developer preview only. Read the release notes for availability, compatible app builds and current validation scope.
