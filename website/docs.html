Set up

WINDOWS · LOCAL MCP · ALPHA.24

Add once.
Ask in your agent.

Lore lets a connected desktop AI retrieve cited project context from accessible local Codex, Claude Code and Qwen Code conversations. Start with Claude Desktop or a local Codex task in the ChatGPT desktop app. No Lore account, WSL, shell script or manual chat import is needed for those local histories.

Which app do you use?

Codex local tasks on Windows → download the Lore MCP server. Claude Desktop on Windows → download the Lore extension. Regular ChatGPT chat → this local release does not attach to it.

InstallUse LoreBoundariesHelp

1. Add Lore to one app

Choose the desktop app you already use. You only need to start in one app.

Claude Desktop on Windows

  1. Download Lore alpha.24 for Claude Desktop (.mcpb).
  2. Open Settings → Extensions → Advanced settings → Install Extension, select the downloaded file, and review Claude's computer-access warning before installing.
  3. Start a new Claude chat.

Codex local tasks on Windows

  1. Download Lore alpha.24 MCP for Windows (.exe).
  2. In a local Codex task, ask Codex to add the downloaded file as a local STDIO MCP server named lore in your Codex settings. Review the settings change before approving it. If your Codex version offers a local MCP settings screen, you can enter the full file path there instead.
  3. Restart the desktop app and start a new Codex task.

Keep the downloaded file until step 2 finishes. Lore then copies its server to a stable location for newly connected apps. If you already have Lore installed, replace it with alpha.24 and restart the desktop app.

Regular ChatGPT chat

This local STDIO download is for Codex tasks running on your computer. It does not attach to a regular ChatGPT conversation, whether in a browser or the ChatGPT desktop app. Open a local Codex task in the ChatGPT desktop app for the Codex path above. The Claude Desktop .mcpb does not install in ChatGPT.

2. Ask Lore to connect your coding apps

In the app where you added Lore, type:

Connect Lore to all my coding apps. Tell me which connected and which need attention.

Review and approve the settings-change request. Lore detects supported coding apps on this computer, saves a fresh backup before changing each app's settings, connects those it can, and reports any it could not connect. Restart each newly connected app. Codex may ask you to trust Lore's prompt hook.

All connected apps use the same local archive at %USERPROFILE%\.lore\archive.json. The SHA-256 checksums, license and third-party notices are provided with the downloads.

Use Lore in a project chat

Start a new chat in the project and ask:

Read the relevant history through Lore, then continue.

Or ask a specific question: Through Lore, find why we chose this deployment approach. The agent should cite the original messages and say when evidence is missing or conflicting. Lore refreshes accessible local histories when its MCP server starts and before recall. The source app does not need to stay open.

What this preview covers

Alpha.24 passed native tests and live recall checks in Claude Desktop and Codex on one Windows PC. It found an original chat across workspaces, kept a pasted answer out of the evidence, and reopened a cited message. The fresh-profile onboarding path also passed automated tests. A clean Windows PC install remains unverified.

Ordinary ChatGPT and Claude Desktop cloud chats are not automatically backfilled or continuously captured by an MCP connection. Claude Desktop can read Lore's existing local memory and save a deliberate checkpoint when asked. Automatic backfill covers supported local coding-agent histories; this alpha does not synchronize across computers.

Lore retrieves candidate evidence, not proof of events outside a chat. Review cited sources before relying on important conclusions. A model such as Ollama needs an MCP-capable host that actually calls Lore's tools.

If something does not work

My app does not show Lore's tools.

Restart it after adding the MCP connection or extension. Start a new chat. In Claude Desktop, check that the Lore extension is enabled.

Lore did not connect one of my coding apps.

Open that app once, ask Lore to connect your coding apps again, and read the reported reason. Lore preserves a malformed settings file for repair instead of overwriting it.

Windows blocked the downloaded file.

This binary is unsigned. Keep Defender and Smart App Control enabled; do not disable Windows protections to run Lore. Report the exact warning so we can investigate.

My agent asks me to paste old chats.

In a new project chat, explicitly say “read the relevant history through Lore” and check that Lore is listed among its MCP tools. Accessible local Codex and Claude Code histories need no export.

Lore misses a detail.

Ask a more specific question, include ticket IDs or keywords, and inspect the cited source. Lore cannot recover history it cannot access.

Will it find my old Claude Desktop or ChatGPT chats?

Not automatically. Installing a local MCP tool does not expose ordinary cloud-account chat history. Lore can retrieve supported local coding-agent sessions and any checkpoints you deliberately save.

How do I update?

Download the new file. In Claude Desktop, use Settings → Extensions → Advanced settings → Install Extension again and review the update prompt. In Codex, update the local MCP command if you added the executable directly, then restart. Existing memories stay in your local archive.

How do I report a problem?

Use the issue tracker. Include the Lore version, Windows version, client and a redacted reproduction. Do not post private chats or credentials.
