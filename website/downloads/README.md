# Lore for Windows — 0.10.0-alpha.24

Choose one desktop app to start:

- **Claude Desktop:** install `lore-memory-windows.mcpb` through Settings → Extensions → Advanced settings → Install Extension. Review Claude's computer-access warning.
- **Codex local tasks in ChatGPT desktop:** add `lore-mcp.exe` as a local STDIO MCP server named `lore`, then restart the app. Regular ChatGPT chat does not use this local connection.

In that app, ask: “Connect Lore to all my coding apps. Tell me which connected and which need attention.” Review the settings-change request and restart newly connected apps. The [setup guide](../docs.html) has the exact steps.

Lore automatically indexes accessible **local Codex, Claude Code and Qwen Code** histories. Installing this MCP does not automatically capture ordinary Claude Desktop or ChatGPT cloud chats. This alpha is unsigned; a clean Windows PC install is not yet verified. Keep Windows protections on if a warning appears.
