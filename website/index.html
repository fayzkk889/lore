Add Lore to one app

Install the Lore extension in Claude Desktop, or add the native Lore MCP server in Codex. No WSL, shell script or Lore account is required.

02

Ask it to connect your coding apps

Type “Connect Lore to all my coding apps.” Approve the settings change and restart newly connected apps. Then ask any connected agent to read relevant history.

A FEW STRAIGHT ANSWERS

Before you
get started.

Is Lore free? Is it open source?

This alpha is free under its bundled Free Binary License. The current implementation is closed source; older MIT-licensed releases keep their original terms.

Does Lore need its own account or hosted server?

No. Ordinary memory operations use your local archive. Your chosen AI provider receives the excerpts supplied to its model, subject to that provider’s policies.

Will it remember everything perfectly?

No. Lore retrieves relevant evidence from available history; it cannot prove an action happened outside the chat or recover a message it never had access to.

Could Windows block it?

Yes. The executable is unsigned. Alpha.24 ran on our test PC, but a clean-PC install is unverified. If Windows blocks it, keep protections on and report the exact warning.
