01

Install and connect

Install Lore, run lore connect to connect detected clients, and restart your client. The guide also shows how to connect one client explicitly.

02

Work as usual

Lore discovers accessible local Codex, Claude Code, and Qwen Code history during recall. You don’t need to keep exporting those chats.

03

Ask for the history

In a connected client, ask it to read relevant history through Lore. It retrieves a compact context pack with source references.

Default global guidance supports the plain continuation request in Codex, Claude Code, and Qwen Code. Other hosts may need you to name Lore explicitly.

A FEW STRAIGHT ANSWERS

Before you
get started.

Is Lore free? Is it open source?

Lore is free during its beta. The current implementation is closed source; public GitHub contains downloads and documentation. Earlier MIT releases retain their original licence.

Does it need an API key or send my chats to Lore’s servers?

Ordinary memory operations run locally and need no Lore API key or hosted memory service. Retrieved context is supplied to the AI client you choose, whose data policies still apply.

Will it remember everything perfectly?

No. Lore retrieves relevant historical evidence, with a bounded context budget and source references. Missing, incomplete or conflicting history still needs careful handling by the agent.

What about Windows warnings?

Beta executables and installers are unsigned. SmartScreen, Smart App Control or workplace policy can warn or block them. Keep protections enabled and report the exact error if installation is blocked.
