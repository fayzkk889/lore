Connect Codex

Install Ubuntu WSL 2, download the Lore MCP preview, and run its Codex setup script. No new native Windows Lore executable is involved.

02

Use accessible local history

Lore can discover local Codex, Claude Code and Qwen Code session files when they are accessible on this computer. Your archive remains local.

03

A FEW STRAIGHT ANSWERS

Before you
get started.

Is Lore free? Is it open source?

This preview is free to use under its bundled Free Binary License. The current implementation is closed source; older MIT-licensed releases keep their original terms.

Does Lore need its own account or hosted server?

No. Ordinary memory operations use your local archive. Your chosen AI provider receives the excerpts supplied to its model, subject to that provider’s policies.

Will it remember everything perfectly?

No. Lore retrieves relevant evidence from available history; it cannot prove an action happened outside the chat or recover a message it never had access to.

Why WSL?

New unsigned native Windows builds were blocked by Smart App Control on our test PC. This preview runs a Linux MCP server inside Ubuntu WSL 2. WSL must already be installed; this is not a one-click setup for every Windows user.
