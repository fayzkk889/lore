The MCP server

Ordinary Lore memory operations use local storage. This preview does not require a Lore account, Lore API key, or hosted memory service. The default archive is %USERPROFILE%\.lore\archive.json. Lore can read accessible local coding-agent session files during recall.

Your connected AI client receives the excerpts it retrieves through Lore. If that client uses a cloud model, its provider may receive those excerpts under its own data policies. Local memory storage does not make the AI client itself offline.

This MCP-only package does not include the earlier browser extension. It does not automatically read your ChatGPT or Claude browser account history. You control whether to import or capture cloud-only chats separately.

This website

This static website has no analytics scripts, signup forms or advertising trackers. It uses locally served styles and scripts. Cloudflare processes requests to serve the site; see Cloudflare’s privacy policy. External links take you to services with their own policies.

Reporting a problem

Use GitHub Issues. Do not include private chat history, passwords or API keys in a public report. Share a redacted reproduction instead.
