The Lore app

Ordinary memory operations use local storage and do not require a Lore account, API key, hosted memory service or analytics. Accessible local coding-agent transcripts are discovered when memory is recalled. The default archive is ~/.lore/archive.json.

A connected AI client receives the context it retrieves through Lore. Its provider’s data policies apply. Local storage does not mean your chosen cloud AI runs offline. Lore’s original coding-agent functionality can also connect to providers you configure; that is separate from local memory operations.

The browser extension preview

Capture starts off and is enabled per saved conversation. Visible messages from supported ChatGPT and Claude layouts are sent to your installed Lore app through native messaging. No Lore cloud service receives those messages.

Browser storage contains conversation URL attachments, project identifiers, consent settings and capture status. It does not store transcript bodies. Captured conversations stay in Lore’s local archive. The extension does not access provider credentials, cookies or private account APIs.

Insert and Copy are explicit actions. Lore does not press Send. When you send retrieved context to an AI provider, that provider receives it. Capture is refused in incognito. Pause stops subsequent captures; an in-flight save may finish. To remove a local captured conversation, use Lore’s forget operation through a connected agent. Provider-side originals are unaffected.

This website

This static site has no analytics scripts, signup forms or advertising trackers. It uses system fonts and locally served styles/scripts and the browser clipboard only when you click a Copy button. Its hosting provider processes network requests to serve the site; see Cloudflare’s privacy policy. Links to GitHub and AI providers take you to services with their own policies.

Reporting a problem

Use GitHub Issues for product problems. Do not include private chat history, passwords or API keys in a public report. Share the version, client, OS and a redacted reproduction instead.

Read the distributed app’s privacy documentation.
