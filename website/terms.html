The current Lore MCP alpha is closed source and free to use under the Free Binary License included with the download. The package also includes third-party notices. Read those files for permissions, restrictions and warranty terms. Earlier MIT-licensed releases keep their original terms.

Alpha availability

This native Windows package requires no WSL. The alpha.24 Claude Desktop and Codex handoff passed a live test on one PC. A clean-PC install and warning-free execution of the unsigned binary have not yet been verified. Ordinary cloud chats and the older browser extension are outside this package.

Retrieval can be incomplete, and client/model behavior varies. Check cited evidence before relying on an answer, especially for claims about actions outside the chat. See the setup guide's boundaries.
